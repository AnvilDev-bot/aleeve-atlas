# 配置与交互指南

本文档详细介绍 **袖里舆图（Aleeve Atlas）** 的界面操作、快捷标点、史莱姆区块设置、配置文件选项以及地图缓存机制。

---

## 一、 全屏世界地图（默认按 `M` 打开）

### 1. 基础浏览與交互

* **平移与缩放**：按住**鼠标左键**拖动地图；滚动**鼠标滚轮**以鼠标指针为中心平滑缩放（最低支持 `0.05` 倍极小缩放）。
* **坐标与信息栏**：界面底部会实时显示鼠标所指位置的 **XYZ 坐标**、**方块名称**、**所在群系**，以及该位置的**领地名称**（若安装了领地类模组）。
* **右键快捷菜单**：
* **右键点击空白处**：可快速在此处**新建路径点**、**发送坐标到聊天栏**，或**直接传送**（自动执行 `/tp` 指令，需拥有服务器传送权限）。
* **右键点击已有路径点**：可将该路径点**分享给队伍**、**传送**、**发送坐标**或**删除**。

### 2. 路径点管理与分享

* **列表操作**：在侧边路径点列表中，需**先左键点击选中条目**，底部的「编辑、显示/隐藏、队伍分享、传送、公开/私密、删除」按钮才会激活。
* **可见距离**：新建路径点的默认可见距离为 `-1`（代表无论多远**始终显示**）；若设为正数，则代表最大显示距离（超出距离后自动隐藏，兼容旧存档设置）。
* **一键分享给队伍**：点击世界地图顶部的「**分享给队伍**」按钮，会将当前地图视野内所有已启用且非私密的路径点一键发送给队友（*注：标记为“私密”的路径点不会被发出*）。

## 二、 小地图（HUD）

### 1. 视野与缩放

* **视野缩放**：默认缩放为 `1.5` 倍（约显示周围 96 格宽的地形），可通过 `=` 和 `-` 键随时放大或缩小视野。
* **临时居中放大**：按住 `Z` 键，小地图会平滑移动至屏幕正中央并放大，松开后自动归位，适合跑图时快速看路。
* **丝滑移动与旋转**：小地图中心绑定玩家的精确坐标（`Vec3`），移动时画面平滑无顿挫，不会出现按整格跳动的现象。当开启“随视角旋转”（未锁定北向）时，地图背景会随视角转动，但小地图边缘的 **N/S/W/E 方向字母、路径点图标和雷达头像始终保持正立**，方便辨认。

玩家自身指示器可以在客户端设置的小地图和世界地图分组中分别选择“抗锯齿水滴形”或“原版指示器”，默认均为水滴形，修改后立即生效。两种样式都有黑色描边；原版样式使用原版地图玩家图标，支持资源包替换。小地图指示器随面板尺寸和按住 `Z` 的放大状态缩放，世界地图指示器保持固定界面尺寸。小地图随视角旋转时指示器固定朝上，锁定北向时和世界地图中的指示器跟随玩家朝向。

### 2. 洞穴模式与环境表现

* **自动切层**：小地图和世界地图共同检测玩家上方 3×3 范围的实心顶棚，不以海平面判断洞穴。树叶、流体和透明方块不算顶棚；洞口切换至少间隔一秒，避免闪烁。
* **普通洞穴**：默认按 16 格高度区间保存分层地图，从玩家上方最多 4 格开始向下扫描最多 30 格，只显示遇到空气或流体后暴露的地面。高度改变时更新精确截面，缓慢上下移动也会刷新；较深地面默认调暗，发光方块保持亮度。
* **下界**：默认使用完整洞穴模式，从每列顶部穿过外层基岩和岩层，再显示内部暴露的地形与熔岩。站到顶棚上方时恢复地表地图。普通维度与下界类维度均可分别选择关闭、分层或完整模式。
* **光照联动**：开启 `minimap.light_brightness` 后，小地图的整体明暗会随玩家所处位置的实际光照强度动态变化。

## 三、 路径点、快捷标点（Ping）与生物雷达

### 1. 游戏内 3D 标记表现

所有的世界内标记均渲染在 HUD 界面底层，**绝不会遮挡准星、小地图或其他界面 UI**：

* **路径点**：在游戏画面中显示为 **75% 透明度的菱形图标 + 名称**（死亡点在地图上则显示为醒目的**红色叉号**）。平时只显示图标，当**准星靠近路径点时才会浮现带深色底衬的距离数字**，既清晰又不挡视野。
* **临时标点（Ping）**：在游戏画面中显示为 **75% 透明度的圆形图标**（与菱形的固定路径点区分），并**始终显示距离**。

### 2. 中键快捷标点（Ping）

无论是在**正常游戏画面**中看着方块，还是在**全屏世界地图**上指着某处，都可以直接使用鼠标中键标点（可在按键设置中修改绑定，且**不影响原版中键选取方块或旁观者中键传送**）：

* **短按鼠标中键**：直接在目标位置打一个「一般」临时标点。
* **长按鼠标中键**：呼出四向标点轮盘（基于 `AnvilLib-Wheel`），拖动鼠标选择 **「危险」「警告」「一般」「前往」** 四种标点之一，松开中键即可发出。

同时安装支持 Atlas 联动的 MiddleKeyPing 时，世界内和世界地图的中键短按、轮盘内容、世界内渲染及网络发送均由 MiddleKeyPing 提供。地图轮盘使用一般、警告、前往、敌人四个选项，发送到鼠标所指的地图坐标；取消或发送后返回地图。世界内按键使用 MiddleKeyPing 的配置，世界地图使用鼠标中键，制图选区中的中键继续用于拖动。

联动时，多人标点需要服务端和参与客户端安装 MiddleKeyPing。坐标标点发给同维度玩家，实体标点发给跟踪目标的玩家；Atlas 在小地图和世界地图上显示收到的标点，并更新实体坐标。有效期与数量上限遵循 MiddleKeyPing，默认保留 300 个游戏刻和 6 个标点。Atlas 的 `ping.channelMode` 不参与这些标点的发送。

### 3. 生物雷达显示模式

雷达图标经过缩窄与边界裁剪处理，不会溢出小地图边框。支持在设置中切换以下四种模式：

1. **始终显示图标**：直接显示玩家头像与生物图标。
2. **仅显示圆点**：用简洁的色点代替具体图标。
3. **按住玩家列表键（Tab）显示图标**：平时隐藏或简化，按住 `Tab` 键时才显示具体图标。
4. **关闭**：完全隐藏实体雷达。

## 四、 区块网格与史莱姆区块

* **网格与覆盖层**：小地图和世界地图均可独立开启**区块边界网格**与**绿色史莱姆区块覆盖层**（在全屏世界地图中，当画面缩小到 `0.8` 倍以下时，会自动隐藏网格和史莱姆区块以防画面杂乱）。
* **如何设置世界种子（查看史莱姆区块）**：
* **单人游戏**：模组会自动读取当前存档种子，无需手动设置。
* **多人服务器（有 OP 权限）**：管理员在游戏内执行一次原版 `/seed` 指令后，客户端会自动捕获并保存服务器返回的种子，并在动作栏弹出提示。
* **多人服务器（已知种子手动设置）**：普通玩家可在聊天栏输入客户端指令：
```mcfunction
/aleeveatlas slime_seed <种子数字>

```

*注：设置的种子会独立保存在当前服务器对应的数据文件夹下，不会与其他存档或服务器串档。*

## 五、 常用配置项参考

你可以在全屏世界地图（`M`）中直接打开图形化配置界面，或手动编辑 `<游戏目录>/config/aleeve_atlas-client.toml`：

| 配置项键名 | 作用说明 | 默认值 / 范围 |
| --- | --- | --- |
| `caves.mode` | 普通维度洞穴模式 | `LAYERED`，可选 `OFF`、`FULL` |
| `caves.ceiling_dimension_mode` | 有顶棚维度的洞穴模式 | `FULL`，可选 `OFF`、`LAYERED` |
| `caves.depth` | 分层模式向下扫描的最大深度 | `30`（范围 `1 ~ 64` 格） |
| `caves.depth_shading` | 按洞穴深度调整地面明暗 | `true` |
| `minimap.scale` | 小地图整体 UI 尺寸缩放倍率 | `0.5` ~ `4.0` |
| `minimap.player_indicator` | 小地图玩家自身指示器样式 | `ANTIALIASED_DROPLET`，可选 `VANILLA` |
| `world_map.player_indicator` | 世界地图玩家自身指示器样式 | `ANTIALIASED_DROPLET`，可选 `VANILLA` |
| `minimap.show_chunk_grid` | 在小地图上显示区块边界网格 | 布尔值 |
| `minimap.show_slime_chunks` | 在小地图上高亮显示史莱姆区块 | 布尔值 |
| `minimap.light_brightness` | 小地图画面亮度随玩家周围光照变化 | 布尔值 |
| `minimap.show_time` | 在小地图下方显示当前游戏时间 | 布尔值 |
| `world_map.show_chunk_grid` | 在全屏世界地图上显示区块网格（缩放 `<0.8` 时自动隐藏） | 布尔值 |
| `world_map.show_slime_chunks` | 在全屏世界地图上显示史莱姆区块（缩放 `<0.8` 时自动隐藏） | 布尔值 |
| `world_map.compass_position` | 世界地图罗盘方向标的角落位置（左上/右上/左下/右下） | 默认 `右下` |
| `world_map.compass_size` | 世界地图罗盘方向标的尺寸大小（带半透明黑底投影） | `48`（范围 `32 ~ 192`） |

## 六、 数据存储与技术说明（服主 / 开发者参考）

### 1. 缓存目录与换IP防丢图机制

所有地图缓存与路径点数据统一存放在 `<游戏目录>/data/aleeve_atlas/` 下：

* **单机存档**：使用 `mapdata/sp_<实际存档文件夹名>_<种子>/`，保留中文名称。局域网房主继续使用这个目录，避免开放 LAN 后切换缓存。
* **服务器与 LAN 成员**：服务端首次启动时生成 UUID，并保存到世界存档的 `data/aleeve_atlas_map_cache_identity.dat`；玩家加入时下发同一个 UUID。远程客户端使用 `mapdata/server_<UUID>/`，更换 IP 或 LAN 端口后仍访问同一份缓存。未收到标识时使用 `mapdata/server_<IP或域名及端口>/`。
* **路径字符与旧缓存**：文件系统禁止的字符采用 `%XX` 转义，例如地址中的 `:` 保存为 `%3A`。地图、路径点和种子使用同一身份目录；不自动迁移旧缓存。
* **切换配色免重跑图**：区块缓存底层记录的是方块状态色板（Palette）索引与高度数据。因此当你修改地图颜色方案时，客户端会直接根据已有色板实时重绘地图，无需重新进服或重新跑图。
* **洞穴缓存**：与地表隔离，完整洞穴保存在维度目录的 `caves/full/`，分层洞穴保存在 `caves/layer_<高度区间>/`。洞穴视图不叠加导入的地表地图；现有队伍同步协议仍只同步地表缓存。
* **防崩档与损坏自愈**：地图文件采用“同目录临时文件 + 原子替换”方式写入，即使游戏意外崩溃或强制关闭也不会产生写一半的坏档。若读取到损坏的区域文件，模组会自动将其重命名为 `<文件名>.corrupt` 留作诊断备份，并在你经过该区域时重新生成正常地图。

### 2. API 与网络协议

* **标点显示控制 API**：其他模组可在客户端主线程调用 `MinimapPingAPI.setWorldPingsEnabled(boolean)` 来开启或隐藏 3D 视界中的临时标点（通过 `MinimapPingAPI.isWorldPingsEnabled()` 查询状态）。关闭后仅隐藏 3D 画面中的标点，小地图与世界地图上的标点依然保留。
* **外部标点操作 API**：`setWorldInputEnabled(boolean)` 控制内置世界内按键；`setMapInput(MapPingInput)` 注册地图短按与轮盘操作，传入 `null` 恢复内置操作。`registerLocalPing(MapPingData)` 只更新客户端显示，适用于已有网络广播的模组；相同标点 ID 更新数据时不重复触发创建事件。
* **网络协议规格**：当前网络协议版本 `PROTOCOL_VERSION` 为 `5`（客户端与服务端必须保持协议版本兼容）。握手阶段下发服务端地图缓存标识，地图同步采用差异化的方块状态色板负载传输；单区块色板收发上限与上行拆包预算对齐，网络 NBT 解码配额上限为 `4 MiB`。

## 结构图标、搜索与提醒

支持五类村庄、林地府邸、海底神殿、丛林神庙、沼泽小屋和试炼密室。单机和双端安装时，玩家自然加载区块并完成地图采样后发现结构；地表和洞穴采样均按水平范围解锁结构。普通发现只读取已加载区块，旧地图区域需要再次途经或接收队友的结构记录。

世界地图左上角的“结构”按钮打开侧栏。点击类型按钮切换筛选，选择“搜索已知结构”按距玩家的水平距离排列结果；点击列表或地图图标定位目标，可收藏具体结构，也可关注整个类型。图标使用原版地图资源，跟随资源包更新。收藏和关注设置只保存在本地。

服务端 `structures.allow_unexplored_search` 默认关闭。开启后，“查找最近结构”从玩家当前位置调用原版结构查找，返回最近的一处目标并保存为“搜索发现”，保留地形迷雾。该操作可能加载结构起点数据，每名玩家两次查询间隔至少 10 秒。

结构记录随地图增量同步和“分享给队伍”操作分批共享，接收方直接保存记录。关闭队伍同步后仍可使用个人结构功能。连接旧服务端时可以查看和搜索已有本地记录。

客户端 `structure_notifications` 默认开启。接近收藏结构或关注类型的水平包围盒 64 格内会显示行动栏提醒，忽略高度；离开 80 格范围后再次接近才重新提醒。多个目标依次提示，同一目标同时被收藏和关注时只提示一次。

## 原版地图导入与选区制图

这些功能需要单机或服务端安装支持本功能版本的袖里舆图；不依赖小队同步开关。

- **导入**：主手或副手持有已填写地图，按 `M` 后点击「导入地图」。主手优先。快照包括原版地图底纹和已探索图像，离手和重登后保留；再次导入才更新。不同维度的地图保存到对应维度，不会投射到当前位置。
- **藏宝图**：导入时同时生成固定目标路径点，重复导入不新增重复点，也不覆盖手动编辑。名称中的「参考高度」表示地图没有提供宝箱实际埋深。路径点默认不自动分享，可在编辑界面开启分享。
- **旗帜**：导入时将原版地图中已标记的旗帜保存为普通路径点，保留真实坐标、底色和自定义名称；未命名旗帜使用对应颜色的原版旗帜名称。名称按路径点分享协议最多保留 128 个字符。主副手均支持，单机或服务端需要安装支持旗帜导入的版本，关闭队伍同步后仍可使用。同一维度、同一原始位置的旗帜只导入一次，地图复制件和不同地图中的同一旗帜也会去重。重登后仍保留，重复导入保留玩家修改；原版地图中移除旗帜后，已导入路径点由玩家手动删除。旗帜路径点默认仅本地保存，可在编辑界面开启分享后手动分享给队伍。
- **显示**：实际探索地形优先于导入图像；重叠导入图像优先采用较高清晰度，其次采用较新的导入。洞穴层不叠加原版地表地图。
- **制图**：手持空白地图打开世界地图，点击「制图」，灰色选区会吸附到原版 0 级地图网格，每张覆盖 128×128 格。左键进入预览、中键拖动平移、滚轮缩放，右键或 Esc 退出选区。
- **预览与材料**：预览只包含已知地表内容，未知部分保留空白，完全未知的区域不能制作。默认制作普通地图；勾选「固定地图」则制作锁定快照，生存模式需要并额外消耗一块普通玻璃板。每次制作消耗一张空白地图，创造模式不消耗材料且锁定不需要玻璃板。取消和校验失败不扣材料。
- **结果**：单张空白地图直接转换；持有整叠时成图放入背包，背包满则掉落。成图是原版地图，可复制、放进展示框、放进箱子交给不同队伍或稍后上线的玩家。未锁定地图继续随原版探索更新，之后可用原版制图台扩图。

导入快照位于地图缓存对应维度下的 `imported_maps/`，与方块采样缓存独立，不会通过小队区块同步自动转发。
