# 配置与交互说明

## 世界地图交互

- 单击鼠标中键：在按下位置创建“一般”临时标点。
- 长按鼠标中键：通过 AnvilLib-Wheel 打开危险、警告、一般、前往四类轮盘，松开中键执行当前选择。
- 鼠标右键空白位置：菜单提供创建路径点、传送到该位置和发送坐标到聊天。传送会发送服务器 `tp` 命令，需要服务器允许玩家使用传送命令。
- 鼠标右键已有路径点：菜单提供队伍分享、传送、发送坐标和删除。
- 世界地图顶部的「分享给队伍」会发送当前视野内全部可分享的启用路径点，私密路径点不会发送。
- 地图缩放以鼠标位置为锚点并平滑插值，打开地图时会执行缩放进入动画。
- 鼠标左键拖动：平移地图，画布重定位时保持地形与世界坐标一致。
- 界面底部：显示鼠标位置的方块、群系，以及该位置存在领地时的领地名称。
- 方向标可通过 `world_map.compass_position` 选择左上、右上、左下或右下角，通过 `world_map.compass_size` 设置整体大小（`32 ~ 192` GUI 缩放像素，默认 `72`）。四个方向臂的逆时针半边为空心，图形与文字均带黑色半透明投影，并随大小配置一起缩放。

- 新建路径点的可见距离默认为 `-1`，表示始终显示；正数表示最大显示距离，旧存档中的数值继续按原距离处理。
- 路径点列表先点击选中条目，再使用底部操作按钮；未选中时编辑、显示切换、队伍分享、传送、公开/私密和删除均不可用。
- 雷达显示模式为「始终显示图标」「仅显示圆点」「按住玩家列表键显示图标」和「关闭」。实体图标尺寸缩小一半并在地图边界内裁剪。

## 小地图交互

- 默认视野缩放为 `1.5` 倍，显示约 96 方块宽的地形。`=` 与 `-` 分别放大和缩小视野，可在键位设置中修改；`minimap.scale` 控制界面尺寸倍率（`0.5 ~ 4.0`）。坐标、群系、光照和时间信息均相对于小地图水平居中。
- 小地图地形中心使用玩家的精确 `Vec3` 坐标，移动时不会按方块坐标跳动。按住 `Z` 时小地图尺寸和位置平滑过渡到屏幕中央，松开后平滑恢复。
- `minimap.show_chunk_grid` 和 `world_map.show_chunk_grid` 分别显示区块边界；`minimap.show_slime_chunks` 和 `world_map.show_slime_chunks` 显示绿色史莱姆区块覆盖层。世界地图缩放倍率最低为 `0.05`，左下信息栏显示鼠标指向方块的 XYZ 坐标。小地图圆形与方形边框向外加粗 3 像素，遮盖地形和覆盖层可能溢出的边缘像素。
- 使用客户端命令 `/aleeveatlas slime_seed <seed>` 设置当前存档或服务器的世界种子，种子保存在该世界对应的数据目录，不会影响其它存档或服务器。未设置时，单人主机会读取存档种子；服务器管理员执行 `/seed` 后，客户端会记录并保存返回的种子，同时在动作栏提示。
- 洞穴模式显示玩家所在层附近空气空腔下方的地面截面，并使用半透明黑色背景；玩家上下移动超过阈值时重新采样对应层。
- `minimap.light_brightness` 启用后，小地图亮度随玩家当前位置的最大本地光照强度变化；`minimap.show_time` 单独控制时间文字。
- 未锁定北向时，地形与标记位置随视角旋转，图标、路径点符号、雷达图标和 NSWE 文字保持屏幕正向。
- 小地图边缘显示 NSWE 方向文字。

## 世界内标记

短按中键在准星目标位置创建“一般”临时标点，长按中键打开四类轮盘，松开执行当前选择。默认使用鼠标中键，可在键位设置中重绑定；标点处理保留原版中键选取方块、旁观者传送等行为。

路径点在 3D 视界中显示为 75% 不透明度的光滑菱形与名称，地图上的死亡点使用红色叉形。准星接近路径点时显示距离，距离文字使用不透明深色底，便于与地形区分。

临时标点显示为 75% 不透明度的圆形，与路径点菱形区分，距离始终显示。世界内标记在 HUD 之前绘制，不遮挡准星、小地图或其它 UI。世界内临时标点默认启用，外部模组可在客户端主线程调用 `MinimapPingAPI.setWorldPingsEnabled(boolean)` 调整显示状态，并通过 `MinimapPingAPI.isWorldPingsEnabled()` 查询；禁用后小地图与世界地图仍继续显示临时标点。

## AnvilLib 依赖

双端必需 `anvillib_config`，客户端另需 `anvillib_wheel`、`anvillib_rendering` 与 `anvillib_util`。模块版本必须与 Minecraft 1.21.11 对应。

## 地图缓存恢复

地图缓存与路径点数据统一位于 `<game_dir>/data/aleeve_atlas/`。区块使用方块状态色板记录采样结果，像素保存色板索引、高度及配色重算信息；小地图和世界地图在探索时按版本增量刷新，切换颜色方案时直接按现有色板重绘，无需重新进入世界或重新跑图。区域缓存通过同目录临时文件和原子替换写入，避免强制关闭客户端留下半写文件。读取到截断或损坏的区域文件时，原文件会重命名为 `<区域文件>.corrupt` 保留诊断信息，正式路径由后续地图采样重新生成。

- 服务端安装本模组时，登录握手会下发与存档绑定的地图缓存标识；客户端仅使用该标识区分地图缓存，路径点和史莱姆种子继续按服务器或存档标识保存。首次切换时会复制已有地址缓存中的地图数据，旧路径点和种子文件保持原位置。未安装服务端组件时继续使用服务器地址哈希作为地图缓存目录。

## 网络协议

当前 `PROTOCOL_VERSION` 为 `5`。地图差异负载传输方块状态色板，握手额外下发服务端地图缓存标识符，双端必须使用兼容协议版本。单区块色板数据的收发上限与上行拆包预算一致，网络 NBT 解码配额为 4 MiB。
