# 配置与交互说明

## 世界地图交互

- 单击鼠标中键：在按下位置创建“一般”临时标点。
- 长按鼠标中键：通过 AnvilLib-Wheel 打开危险、警告、一般、前往四类轮盘，松开中键执行当前选择。
- 鼠标右键空白位置：打开“创建路径点”菜单，进入路径点编辑表单。
- 鼠标右键已有路径点：打开“删除路径点”菜单，删除本地记录；启用自动同步时同时通知队友删除。
- 鼠标左键拖动：平移地图，画布重定位时保持地形与世界坐标一致。
- 界面底部：显示鼠标位置的方块、群系，以及该位置存在领地时的领地名称。
- 方向标可通过 `world_map.compass_position` 选择左上、右上、左下或右下角，通过 `world_map.compass_size` 设置整体大小（`32 ~ 192` GUI 缩放像素，默认 `72`）。四个方向臂的逆时针半边为空心，图形与文字均带黑色半透明投影，并随大小配置一起缩放。

## 小地图交互

- 默认视野缩放为 `1.5` 倍，显示约 96 方块宽的地形。`=` 与 `-` 分别放大和缩小视野，可在键位设置中修改；`minimap.scale` 控制界面尺寸倍率（`0.5 ~ 4.0`）。坐标、群系、光照和时间信息均相对于小地图水平居中。
- 按住 `Z` 时小地图居中并撑满屏幕短边，松开后恢复原位置与尺寸。
- 未锁定北向时，地形与标记位置随视角旋转，图标、路径点符号、雷达图标和 NSWE 文字保持屏幕正向。
- 小地图边缘显示 NSWE 方向文字。

## 世界内标记

短按中键在准星目标位置创建“一般”临时标点，长按中键打开四类轮盘，松开执行当前选择。默认使用鼠标中键，可在键位设置中重绑定；按下时不会触发原版选取方块。

路径点在 3D 视界中显示为 75% 不透明度的光滑菱形与名称，地图上的死亡点使用红色叉形。准星接近路径点时显示距离，距离文字使用不透明深色底，便于与地形区分。

临时标点显示为 75% 不透明度的圆形，与路径点菱形区分，距离始终显示。世界内标记在 HUD 之前绘制，不遮挡准星、小地图或其它 UI。世界内临时标点默认启用，外部模组可在客户端主线程调用 `MinimapPingAPI.setWorldPingsEnabled(boolean)` 调整显示状态，并通过 `MinimapPingAPI.isWorldPingsEnabled()` 查询；禁用后小地图与世界地图仍继续显示临时标点。

## AnvilLib 依赖

双端必需 `anvillib_config`，客户端另需 `anvillib_wheel`、`anvillib_rendering` 与 `anvillib_util`。模块版本必须与 Minecraft 1.21.11 对应。

## 地图缓存恢复

地图缓存与路径点数据统一位于 `<game_dir>/data/aleeve_atlas/`。区块使用方块状态色板记录采样结果，像素保存色板索引、高度及配色重算信息；小地图和世界地图在探索时按版本增量刷新，切换颜色方案时直接按现有色板重绘，无需重新进入世界或重新跑图。区域缓存通过同目录临时文件和原子替换写入，避免强制关闭客户端留下半写文件。读取到截断或损坏的区域文件时，原文件会重命名为 `<区域文件>.corrupt` 保留诊断信息，正式路径由后续地图采样重新生成。

## 网络协议

当前 `PROTOCOL_VERSION` 为 `4`。地图差异负载传输方块状态色板，双端必须使用兼容协议版本。单区块色板数据的收发上限与上行拆包预算一致，网络 NBT 解码配额为 4 MiB。
